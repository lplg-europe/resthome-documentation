# Service requests

:::{rh-description}
Follow the services residents of a serviced residence ask for — cleaning, a repair, a hand — from the request to the work done, billed on the resident's next invoice.
:::

:::{rh-faq}
When is a request billed?
: When it is marked **Done**, if it has a **Service billed** and a unit price. It then lands on the resident's next invoice, like a supplement.

The service is already included in the price. Is it billed?
: No. When its product is listed in **Included in the price** on the residence, the request shows **Included in the price** and nothing is billed.

Can I cancel a request already billed?
: Not directly. Take the line off the resident's supplement envelope first, then cancel the request.

Can I mark a request done from my phone?
: Yes. In the care app, the **Residence** tab lists the requests to do, each with a **Done** button.
:::

A resident asks for a service: a cleaning, a small repair, a light bulb changed.
The **Requests** menu follows each one until it is done, and bills it when it
has a price.

## 1. Record the request

In **Serviced Living → Requests**, click **New**:

- **Resident** and **Residence**;
- **Asked at** — now by default;
- **Assigned to** — who does it;
- **Request** — what is asked;
- **Service billed** — the product to bill; leave it empty when the request is
  not billed. **Quantity** and **Unit price** then appear.

When the service is listed in **Included in the price** on the residence, the
request says so and hides the quantity and the price.

## 2. Mark it done

Click **Done**. **Done at** is filled in, and when the request has a service and
a price, it is added to the resident's open supplement envelope. The month's
generation then brings it onto the invoice. See
[Supplements](../facturation/supplements.md).

The request shows **Billed on**: the line it was billed on.

## Cancelling a request

**Cancel** sets the request aside; **Reopen** brings it back to **To do**. A
request already billed cannot be cancelled until its line is taken off the
envelope.

## Following the requests

**Serviced Living → Requests** opens on the requests **To do**. The **Mine**
filter keeps the ones assigned to you, and the residence's **Open requests**
smart button opens the requests still to do there.
